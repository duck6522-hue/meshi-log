# めしログ

食事と体重を記録する、自分用のカロリー管理アプリです（スマホ向けPWA）。

- **きょう**: 朝食・昼食・夕食・間食ごとに記録。1日の合計カロリーと PFC（たんぱく質・脂質・炭水化物）、糖質・食物繊維・食塩相当量を、目標に対する進捗バーつきで表示
- **食品の検索・追加**: 食品名（ひらがな・カタカナ・漢字）で検索し、g や「1個」「茶碗1杯」などの単位で量を調整して記録
- **バーコード**: 検索画面のバーコードボタンから、カメラで読み取るか数字で入力。アサヒ飲料・伊藤園・テーブルマーク・味の素冷凍食品の 471 商品は公式の JAN コードで最初から登録済み。見つからない商品は一度食品を選ぶと覚え、次からは読み取るだけで出る（覚えた対応は端末内に保存。カメラの映像はどこにも送らない）
- **マイ食品**: よく食べるものを手入力で登録（100gあたり／1食分あたりのどちらでも入力可）
- **メモリー**: 同じ食事で2回以上食べたものを覚えて、各食事の下に「いつもの」として表示（ワンタップで記録）。前日の同じ食事のコピー、よくある組み合わせを保存する「マイセット」も
- **この7日間**: 日別カロリーの棒グラフ、平均、連続記録日数
- **月のふり返り**: 「この7日間」のボタンから。月ごとに記録日数、平均カロリー・PFC・食物繊維・食塩、日別の棒グラフ、運動、体重の変化、よく食べたもの・カロリーの多かったもののランキングと、ひとことを表示（前後の月に切り替え可）
- **レシピ提案プロンプト**: きょうの残りカロリー・PFC、食べたもの、好みを埋めた AI 向けの文面を作ってコピー。AI の回答にある「めしログ: 料理名 | 重さ | kcal | P | F | C」の行を貼り付けると、マイ食品に登録して記録できる（好みと文面は設定で編集）
- **運動**: メニュー（歩く・走る・自転車・ジム・水泳・スポーツ・家事など約50種）と時間、または歩数から消費カロリーを計算して記録。スマートウォッチなどの値を直接入力も可。消費分をその日の目標カロリーに足すかは設定で選べる
- **かんたん栄養診断**: 「きょう」のいちばん下に、カロリー・PFC・食物繊維・食塩の判定と、記録内容に合わせたひとことを表示（夕食前は「ここまで」として判定）
- **画像で保存**: 「きょう」の右上のカメラボタンで、その日の画面全体（栄養診断まで）を縦長の画像1枚にして、共有・保存できる
- **体重**: 日ごとの体重を記録し、推移を折れ線グラフで表示。直近4週間の記録から「1週間で −0.4kg」のようなペース、4週間後の見込み、目標体重に届く日の目安、同じ期間の食事の記録があれば維持できるカロリーの目安を表示
- **設定**: 目標カロリー、目標体重、PFC の目標比率、レシピ提案プロンプト、バックアップの書き出し・読み込み
- **端末内に保存**: データはその端末のブラウザ内（localStorage）だけに保存され、どこにも送信されません。オフラインでも動きます

## 使い方

ビルド不要の静的サイトです。GitHub Pages で `main` ブランチのルートを公開し、スマホのブラウザで開いて「ホーム画面に追加」してください。

手元で試すとき:

```sh
python3 -m http.server 8000   # http://localhost:8000/ を開く
```

## 食品データ

文部科学省「日本食品標準成分表2020年版（八訂）」の全 2,478 品目について、可食部 100g あたりのエネルギー・たんぱく質・脂質・炭水化物（差引き法）・食物繊維総量・食塩相当量を収録しています。JSON 化には [katoharu432/standards-tables-of-food-composition-in-japan](https://github.com/katoharu432/standards-tables-of-food-composition-in-japan)（CC BY 4.0）を利用しました。

`tools/` のリストで、探しやすい名前と成分表にない食品を足しています。

| ファイル | 内容 |
|---|---|
| `tools/common.txt` | 成分表の品目に付ける通称（「ごはん（白米）」「鶏むね肉（皮なし）」など）と目安の単位（「1個＝50g」など）。750 品目 |
| `tools/dishes.txt` | 成分表にない料理（定食、弁当、丼、麺、寿司、鍋、デザート、飲み物、家系・二郎系ラーメンと濃厚つけめんの目安など 896 品）。材料と 1 人前の分量を書くと、成分表の値から栄養を計算する |
| `tools/chains.txt` | チェーン店の公式栄養成分（1食あたり）。吉野家 162・マクドナルド 201・松屋 212・すき家 460・サイゼリヤ 125（カロリーと食塩のみ）・てんや 306・丸亀製麺 120・サブウェイ 152・ゴンチャ 209・ケンタッキー ドリンク 29・ドトール 270・日高屋 124（カロリーと食塩のみ）・サーティワン 188（フレーバー×サイズ、カロリーはコーン別）・セブン‐イレブン 718（関東の販売商品。食物繊維も公表値）・ファミリーマート 137（ホットスナック・中華まん・おでん・コーヒーのみ公表）・ローソン 1,142（関東の表示）・幸楽苑 96・山岡家 47（カロリーのみ）・大戸屋 163（食物繊維つき）・松のや 159・ミスタードーナツ 146・ココイチ 188・はなまるうどん 132（通年メニュー）・スターバックス 376（サイズ別、通常のミルク）品。市販のアイス 191 品・ロッテのガム・キャンディ 82 品（ロッテ・明治・森永製菓・森永乳業は1個・1本あたり、井村屋はカロリーのみ）。重さが公表されていないので、並盛・M・ICED・S などのサイズ単位で記録する |
| `tools/snacks.txt` | 市販のお菓子 861 品、ケンタッキーの料理 51 品・モスバーガー 190 品（公式の重量つき）・冷凍食品 159 品（テーブルマーク 54・味の素冷凍食品 105）、キリンのソフトドリンク 136 品・日本コカ・コーラの飲料 137 品・アサヒ飲料 158 品・伊藤園 165 品・ダイドー 102 品・カゴメ 104 品（自販機・店頭。ml は g とみなす）。江崎グリコ・カルビー・ブルボン・明治・ロッテ・森永製菓・不二家・亀田製菓・有楽製菓の公式サイトの栄養成分表示（1袋あたりなど）をそのまま持ち、作成時に 100g あたりへ換算する。1袋・1枚・全量などの単位つき |
| `tools/jan.txt` | バーコード（JANコード）と市販品の対応。アサヒ飲料の JAN コード一覧と、伊藤園・テーブルマーク・味の素冷凍食品の商品ページから 471 件 |
| `tools/extra.txt` | 成分表にない市販品（サラダチキン、プロテイン、オレオなど 17 品）。一般的な栄養成分表示をもとにした 100g あたりの値 |

料理と市販品はアプリの検索結果に「目安」と表示されます。お店や商品によって差があるので、正確に記録したいものはマイ食品に登録してください。食品を足したいときは上のファイルを編集して作り直します。

```sh
python3 tools/build_foods.py path/to/data.json --check   # 結びつきの確認だけ
python3 tools/build_foods.py path/to/data.json           # foods.json を書き出す
```

Service Worker はネットワーク優先なので、`foods.json` や `index.html` を更新しても `sw.js` の `CACHE` の番号を上げる必要はありません。
